# Coming Bird クローン

`comingbird.yyyywaiwai.com` を模倣した、独立した Next.js 14 アプリです。
リポジトリ直下の AI ツールブログとはビルドもデプロイも完全に分かれています。

## 開発

```bash
cd comingbird
npm install
npm run dev     # http://localhost:3001
npm run build
```

## 現状のスコープ

実物のサイトを直接取得できなかったため、**検索で確認できた機能構成をもとに作った土台**です。
配色・タイポグラフィ・細部のレイアウトは実物と異なります。

実装済みのページ:

| パス | 内容 |
| --- | --- |
| `/` | 新着フィード + 日間ランキング抜粋 + 人気タグ |
| `/ranking` | 日間 / 週間 / 月間 / 総合 の再生数ランキング |
| `/search` | タイトル・投稿者名・タグの全文検索 |
| `/video/[id]` | 動画詳細（統計・タグ・引用元リンク・通報導線） |
| `/import` | X の投稿 URL 登録フォーム |
| `/report` | 権利侵害・不適切コンテンツの通報フォーム |
| `/about`, `/privacy` | サイト説明・データの扱い |

## 意図的に実装していないもの

- **X / Twitter からの動画取得・ダウンロード**。`/import` は URL の形式を検証して受付表示を出すだけで、外部への通信は一切行いません。
- **動画ファイルの保持・配信**。詳細ページの再生面はプレースホルダで、実際の視聴は引用元リンク先で行う導線にしています。
- **フォームの送信先**。`/report` は完了状態を表示するのみで、送信処理は未接続です。

これらを実際に動かす場合は、権利関係と各サービスの利用規約を確認したうえで実装してください。

## デザインを実物に寄せる手順

配色は `app/globals.css` の `:root` にある CSS 変数に集約してあります。
Tailwind 側は `rgb(var(--cb-*))` を参照しているだけなので、**この 1 ブロックを書き換えれば全体の色が入れ替わります**。

```css
:root {
  --cb-bg: 11 15 20;        /* 背景 */
  --cb-surface: 20 26 33;   /* カード面 */
  --cb-accent: 56 189 248;  /* アクセント */
  /* ... */
}
```

フォントは `--cb-font-sans`、コンテンツ幅は `tailwind.config.ts` の `maxWidth.shell` で調整します。

## データ

`lib/sample-videos.ts` のダミーデータを `lib/data.ts` の関数群が読んでいます。
実データに繋ぐときは `lib/data.ts` の各関数の中身だけを差し替えれば、ページ側は変更不要です。
