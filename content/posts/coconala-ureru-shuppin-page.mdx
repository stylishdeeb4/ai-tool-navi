出品したのに、閲覧数だけ増えて注文が入らない。ココナラで最初につまずくのは、たいていこの段階です。

原因はスキル不足ではありません。**買い手が「この人に頼もう」と判断するための材料が、ページに足りていない**だけです。ココナラの購入は、次の3ステップで進みます。

1. 検索結果で**タイトルとサムネイル**を見る → クリックするか決める
2. **サービス説明文**を読む → 依頼できそうか判断する
3. **評価・プロフィール**を見る → 最終的に信用できるか決める

つまり、どこで離脱されているかによって直すべき場所が違います。この記事では3つすべてをテンプレート付きで解説します。

> 📌 出品前の方は[ココナラで稼ぐ完全ガイド](/blog/coconala-kasegu-guide)から読むとスムーズです。

## まず診断｜どこが原因かを切り分ける

やみくもに直す前に、閲覧数を見て原因を特定しましょう。

| 症状 | 原因の場所 | 直すもの |
|---|---|---|
| 閲覧数がそもそも少ない | 検索に出ていない／クリックされていない | タイトル・カテゴリ・サムネイル |
| 閲覧数はあるが注文ゼロ | 説明文で不安が消えていない | サービス説明文・価格 |
| 見積り相談は来るが成約しない | 返信の速さ・提案内容 | 対応スピード・プラン設計 |

**閲覧数が少ないのに説明文だけ直しても意味がありません**。順番を間違えないでください。

## タイトルの作り方｜30文字で「誰の何を解決するか」を言い切る

検索結果に並んだとき、判断材料はタイトルとサムネイルだけです。ここに全力を注ぎます。

### 売れないタイトルの共通点

- 「記事を書きます」← 何万件もある同じ文言に埋もれる
- 「丁寧に対応します」← 全員が言っている
- 「元◯◯が本気で作ります」← 主語が自分になっている

### 売れるタイトルの型

```
【対象】+【提供内容】+【得られる結果 or 特徴】
```

具体例で見てみましょう。

| 悪い例 | 良い例 |
|---|---|
| ブログ記事を書きます | 不動産会社様向けにSEO記事を3日で納品します |
| ロゴを作ります | 開業したての個人サロン向けにロゴを3案ご提案します |
| 相談に乗ります | 副業を始めたい会社員の方の最初の一歩を整理します |
| 資料を作ります | 営業提案用のパワポを構成から作成し即日納品します |

ポイントは**対象を絞ること**です。「みんな向け」は誰にも刺さりません。対象を絞ると母数は減りますが、該当する買い手にとっては「まさに自分のためのサービス」になります。

さらに、可能なら**数字**（3日・3案・即日）を入れてください。具体性がそのまま信頼になります。

## サムネイルの作り方｜3秒で読める文字だけ入れる

サムネイルは装飾ではなく**看板**です。凝ったデザインより、伝わることを優先します。

### 入れるべき要素

1. **サービス内容を示す短い文字**（10〜15文字程度）
2. **他と違う点**（即日納品／修正無制限／実績◯件 など）
3. **視認性の高い配色**（背景と文字のコントラストを強く）

### やりがちな失敗

- 文字が小さい — スマホでは想像以上に縮みます
- 情報を詰め込みすぎ — 3秒で読めない看板は無いのと同じ
- 写真だけ／イラストだけ — 何のサービスか伝わらない

## サービス説明文テンプレート

説明文の役割は、**買い手の不安を先回りして消すこと**です。以下の順番で書けば、必要な情報が漏れません。そのまま埋めて使ってください。

```
■ こんなお悩みはありませんか？
・（買い手が抱える悩みを3つ）
・
・

■ このサービスで解決できること
（納品物によって何がどう変わるかを2〜3行で）

■ 納品内容
・（成果物の形式・ファイル形式・本数など具体的に）
・修正回数：◯回まで無料
・納期：ご入金確認後◯日以内

■ ご購入の流れ
1. 購入前にメッセージでご相談ください
2. ヒアリングシートにご記入いただきます
3. 初稿を◯日以内にお渡しします
4. 修正対応後、納品完了

■ 私について
（経験・実績・なぜこのサービスを提供できるかを3〜4行で）

■ ご注意
・（対応できない範囲を明記）
・（著作権の扱い・二次利用の可否）
```

### 書くときの3つのコツ

**1. 悩みから書き始める**
自己紹介から始めると読まれません。買い手は自分の悩みにしか興味がないので、冒頭で「それ、私のことだ」と思わせます。

**2. できないことを正直に書く**
「なんでも対応します」はトラブルの元です。範囲を明記したほうが、かえって信頼されます。

**3. 購入の流れを具体的に示す**
初めての買い手は「購入後どうなるのか」が分からず不安です。手順を書くだけで注文率は上がります。

## 価格の決め方｜3プランで真ん中を売る

1つの価格だけを提示すると「高いか安いか」の判断になりますが、3つ並べると「どれを選ぶか」の判断に変わります。

| プラン | 位置づけ | 設計の考え方 |
|---|---|---|
| ベーシック | 入口 | 最小限の納品物。相場のやや下 |
| **スタンダード** | **本命** | 一番売りたい内容。最も選ばれる |
| プレミアム | 引き上げ | 手厚い内容。本命を安く見せる役割 |

さらに、オプションで客単価を上げられます。

- お急ぎ納品：+2,000円
- 修正回数の追加：+1,500円
- 商用利用の許諾：+3,000円

実績がないうちは相場より安く設定し、評価が5〜10件たまった段階で値上げします。単価の上げ方は[AIライティングで単価を上げる7つのコツ](/blog/ai-writing-tanka-up)も参考になります。

## 出品後にやる改善サイクル

出品して終わりにせず、2週間ごとに次を回してください。

1. **閲覧数を確認**する（少なければタイトルとサムネイル）
2. **注文率を確認**する（閲覧はあるのに売れなければ説明文と価格）
3. **1か所だけ変える**（同時に複数変えると、何が効いたか分からなくなる）
4. **2週間様子を見る**

地味ですが、これが最短ルートです。最初から完璧なページは作れません。

## まとめ｜直す順番を間違えない

売れる出品ページの要点をおさらいします。

- **タイトル**：対象を絞り、数字を入れて「誰の何を解決するか」を言い切る
- **サムネイル**：3秒で読める文字と、他と違う一点だけ
- **説明文**：買い手の悩み → 解決内容 → 納品物 → 流れ → 注意点の順
- **価格**：3プラン構成で真ん中を売る。実績が付いたら値上げする
- **改善**：閲覧数 → 注文率の順に見て、1か所ずつ変える

ページを直すのに費用はかかりません。今日のうちにタイトルだけでも書き換えてみてください。
