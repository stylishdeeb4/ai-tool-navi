# ココナラ収益設計（AIツールナビ）

ココナラ案件（`lib/affiliates.ts` の `coconala`）は実リンク設定済みだが、
「ココナラ」で検索してきた読者を受け止めるページが存在せず、既存記事内の
言及からの“ついでクリック”しか発生していなかった。

そこで、ココナラ単体で集客 → 登録（無料会員登録が成果地点）まで運ぶ
クラスタ構造を用意する。この文書はその設計図であり、記事を追加するときの
判断基準として使う。

## 1. なぜココナラを軸に置くか

| 観点 | 内容 |
|---|---|
| 成果地点 | 無料会員登録。購入や出品の完了が不要でハードルが低い |
| 読者との距離 | 当サイトの主読者（AI副業を始めたい初心者）が「最初の1円」を得る場所として最短 |
| 記事資産との相性 | 既存の副業系17本すべてから自然に送客できる（ライティング/画像/動画/相談すべて出品可能） |
| 競合 | 「ココナラ 稼ぐ」系は体験談ブログが中心。**AI活用 × 手順化**の切り口は空きがある |

## 2. クラスタ構造（ハブ&スポーク）

```
                 [ハブ] ココナラで稼ぐ完全ガイド
                  /blog/coconala-kasegu-guide
                        ↑         ↑
        ┌───────────────┘         └───────────────┐
 [スポークA] 出品アイデア25選            [スポークB] 売れる出品ページの作り方
 /blog/coconala-ai-shuppin-idea         /blog/coconala-ureru-shuppin-page
   （何を売るか＝検討段階）                （どう売るか＝実行段階）
                        ↑
        既存の副業記事群（AI副業15選 / 主婦 / スマホ / ChatGPT副業 …）
```

- ハブ＝**取引の全体像と手順**。検索意図「ココナラ 稼ぐ / 稼ぎ方 / 副業」を受ける。
- スポークA＝**商材選び**。まだ売る物が決まっていない層を受け、ハブへ返す。
- スポークB＝**転換率改善**。すでに出品したが売れない層を受け、ハブへ返す。
- 3本は相互リンクし、既存記事からは原則ハブへ1本だけ送る（リンクの分散を避ける）。

## 3. 記事内のCTA配置ルール

`{{AFF:coconala}}` は「読者の納得が最大化した直後」にだけ置く。1記事あたり2〜3個まで。

| 位置 | 置く条件 |
|---|---|
| 前半（導入の直後は禁止） | 「登録は無料・出品も無料」と費用面の不安を解消した直後 |
| 中盤 | 売れるジャンル／アイデアを見せ、「自分にもできそう」と思わせた直後 |
| 末尾（まとめの直前） | 行動手順を提示し、次の一歩が「登録」しかない状態にした直後 |

導入直後・見出し直後の設置はしない（読了率とAdSenseポリシー双方に不利）。

## 4. 内部リンク方針

- 既存の副業系記事から、ココナラに触れている箇所をハブ記事へリンクする。
- ハブ記事からは、収益化の周辺論点（確定申告・怪しい副業の見分け方・単価アップ）へ
  返して回遊させる。ハブを行き止まりにしない。
- トップページの `AffiliatePicks` はココナラを先頭に出す（登録ハードルが最も低いため）。

## 5. 効果測定

以下の順で見る。数字が動かないときは上の段から疑う。

1. ハブ記事のインプレッション（Search Console）— 記事が拾われているか
2. ハブ記事のCTR・掲載順位 — タイトルとdescriptionの問題
3. CTAボックスのクリック（A8管理画面のクリック数）— 設置位置と訴求文の問題
4. 成果承認数 — 訴求と実サービスのズレ

## 6. 免責・コンプライアンス

- CTAは `rel="sponsored nofollow noopener"`（`renderAffiliateBox` が付与）。
- 各記事に「※当サイトはアフィリエイトプログラムを利用しています」の表記を保つ。
- 収入は保証しない。「〜が目指せる」など目安である旨を明記し、断定表現を避ける。
- 手数料率・振込条件など変動しうる数値は、公式で最新を確認するよう注記する。

## 7. 今後の追加候補（優先度順）

1. ココナラの手数料・振込・確定申告まわりの実務記事（既存の確定申告記事と相互リンク）
2. 「ココナラ vs クラウドワークス/ランサーズ」比較記事（他ASP案件との併売が効く）
3. 出品ジャンル別の深掘り（ロゴ / 記事作成 / 占い・相談 など需要上位から）
